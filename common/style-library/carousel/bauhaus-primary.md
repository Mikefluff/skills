# Bauhaus primary

**Vibe**: A 1923 Dessau workshop poster reissued as a textbook cover — primary red, yellow, and blue holding hands with pure geometric form, the whole composition arguing that design can be a tool of clear thinking.

**Palette**: Primary red, primary yellow, primary blue (in their pure, slightly desaturated paint values — not screen RGB), pure black for ink, off-white paper. No tints, no shades; flat colour only.

**Typography**: Geometric sans rooted in the Bauhaus typographic experiments. Reference faces — Futura, Avenir, Universal (Herbert Bayer revival), Inter as fallback. All-caps headlines, ranged left, tight tracking. Lowercase only in body. A single rule line per slide.

**Medium**: Pure flat vector — circle, square, triangle as the structural alphabet. No gradient, no texture, no realism. Photographic content only as silhouette knocked into a primary colour.

**Composition**: Strict geometric grid built from circles, squares, and triangles. Hero composition stacks two or three primary shapes in clear hierarchy. Typography ranged left to a grid edge, paired with one bold rule. Slide number set in tabular figures inside a circle.
