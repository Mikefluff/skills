# Holographic iridescent

**Vibe**: A foil sticker catching afternoon light on a record-shop window — colours shifting as the eye moves, no single hue stable, the surface acting more like a prism than a pigment.

**Palette**: Duochrome shifts — pink-to-cyan, lilac-to-mint, peach-to-teal, oil-slick rainbow. Background usually soft pearl white or smoke grey. One deep navy or charcoal for typographic contrast.

**Typography**: Modern grotesque or wide display sans. Reference faces — Aeonik, GT Walsheim, Söhne Breit, Inter Display. Headline at semibold, wide tracking, set against pearl or applied with foil treatment. Caption in pale lavender on a frosted-glass underlay.

**Medium**: 3D render with iridescent-foil shader — colour shifts based on viewing angle, soft prismatic edge highlight, gentle environment map. Surfaces appear thin and lustrous, like sticker foil or anodised metal.

**Composition**: Hero foil-shaded object floating mid-frame, frosted-glass element holding the headline, ambient pearl background, faint prism flare across one corner, slide number inside a small foil cartouche.
