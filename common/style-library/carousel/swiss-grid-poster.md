# Swiss-grid poster

**Vibe**: A 1960s Zurich concert poster pinned to a university corridor — rational, unsentimental, every millimetre placed on purpose, all argument made through grid and weight rather than ornament.

**Palette**: Red lake (Pantone 485 territory), pure black, pure white. Occasional substitution — cobalt blue or yellow ochre in place of red — but never more than two ink colours plus paper. Solid fields only, no gradients.

**Typography**: Neo-grotesque sans dominates entirely. Reference faces — Akzidenz-Grotesk, Helvetica Neue, Neue Haas Grotesk, Inter. Headline tightly tracked, large, ranged left or set against the grid edge. Numbered slides use tabular figures in small caps.

**Medium**: Pure vector, flat ink-on-paper feel, occasional photo silhouette knocked back to a single colour and integrated into the typographic field. No texture, no grain.

**Composition**: 12-column grid, type ranged left, dramatic scale contrast between display and body, large white field forming the dominant element. One bold rule line per slide. Numerical indicators always tabular, top-right.
