# SERVERS NOT STAFF (FAKE AI-WORKFORCE EXPOSÉ)

## Reference orientation

The aesthetic IS the unmasking — pristine Apple-showroom hardware display on the front layer (Mac Mini stack on a glossy platform under cool-cyan spotlights, employee-badge cards bolted on each unit as if it were a person), with HR-paperwork / org-chart / architecture-blueprint overlays revealing the rot beneath: empty role-definition forms, fake org-charts where hardware sits at every role node, accountability checklists stamped UNDEFINED, the proper architecture diagram on the other side showing what a REAL digital employee actually requires (task / data / tools / permissions / constraints / memory / verification / metrics / cost-of-failure / human approval). Cinema-product-launch meets corporate HR-audit.

## When NOT to use

- Sincere AI-engineering / agent-architecture content — would read as parody. Use `cyber-noir` or `blueprint` instead.
- Apple / hardware-product reviews — completely wrong rhetorical posture.
- Real workforce / HR / people-ops content — the badge defacement is a critique, not a celebration.

## Variation hints

- **Hardware ALWAYS top/left, paperwork ALWAYS bottom/right (or vice versa)**: the showroom lie surface is the staged glow; the HR-paper / blueprint is the cold unmasking. Never invert.
- **Use employee-badge framing on EVERY Mac Mini**: photo-frame card with name + role + dept, defaced with red "NOT AN EMPLOYEE" stamp. The badge is the rhetorical wedge — it forces the viewer to see "this is being called a person".
- **The 10 accountability questions are the rhetorical heart**: process / accuracy / logs / rights / approval / errors / accountability / metrics / cost-of-failure / human gate. Each stamped UNDEFINED is the audit verdict.
- **The architecture-blueprint comparison side does the constructive work**: it must show what a real digital employee actually requires — not as a hand-wave, but as a labeled, connected technical diagram. The lie collapses on contrast.
- **Character role**: character is the CTO / HR-AUDITOR / FRACTIONAL-CHIEF-OF-STAFF who's been handed the rack and a clipboard, and is filing the verdict. Cold-eyed knowing smirk. NEVER the founder showing off the stack.

## Real-world references for orientation only

Think the aesthetic of an Apple Mac Mini product launch hero-shot colliding with a corporate-HR onboarding-folder audit. The showroom carnival vs the personnel file, on the same canvas. The style does NOT mimic Apple's branding directly; it borrows the *posture* of pristine product-display photography being interrogated by cold corporate paperwork.

Do NOT inject named brands (Apple, Workday, SAP, BambooHR), named coaches, or named AI-employee products into image prompts. Keep references in this file only.
