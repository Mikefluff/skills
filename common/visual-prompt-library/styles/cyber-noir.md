# CYBER-NOIR / DIGITAL

Use for content that involves AI, technology systems, data, security, or anything with a "looking into the machine" angle. The visual language is **terminal screens, surveillance HUDs, classified dossiers** — high contrast on deep black with neon code colors.

## When NOT to use

- Wellness / health — too anxious.
- Luxury / fashion — too cold.
- Children's content — too dystopian.

## Variation hints

- More matrix green → hacker / data flow energy.
- More signal red → warning / breach / urgency energy.
- More cyan → futuristic HUD energy.
- Heavy amber → military-tech / classified-tier energy.
