# SCIENTIFIC / ACADEMIC

Use for content that needs to feel credible, evidence-based, and intellectually serious. The visual language is **academic journal page + classical serif + restrained palette + structural typography**.

## When NOT to use

- Hype / urgency content — too restrained.
- Consumer / lifestyle — too austere.
- Children's content — too serious.

## Variation hints

- More cream / less white → vintage scholarly journal energy.
- Heavy burgundy accents → humanities-essay energy.
- Heavy forest green → natural-science / botany energy.
- Heavy institutional blue → social-science / policy energy.
- Add ample marginalia → close-reading / annotated-edition energy.

## Default fallback

This is the safe fallback when no style signal clearly matches — restrained, credible, works for almost anything that doesn't lean strongly into another style.
