# GLAMOUR / GLOSSY

Use for content about fashion, beauty, lifestyle, premium brands. The visual language is **Vogue / Elle magazine cover + Didot masthead + soft studio bokeh + gold-foil accents**.

## When NOT to use

- Technical / engineering — wrong register.
- Tactical / military — too soft.
- Children's content — too aspirational.

## Variation hints

- Deep black BG → editorial fashion-shoot energy.
- Champagne gradient → red-carpet energy.
- Ivory cream → beauty-product / lifestyle catalog energy.
- More marble pattern → museum / haute-couture energy.
- Heavier rose gold → cosmetics-launch energy.
