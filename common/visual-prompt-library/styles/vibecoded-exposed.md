# VIBECODED EXPOSED (AI-DASHBOARD VAPORWARE)

## Reference orientation

The aesthetic IS the unmasking — slick cyber-vaporware dashboard on the top layer (glowing neon-cyan metric cards, magenta charts, "12 AI EMPLOYEES ACTIVE", "+320% productivity", "Agent Control Center"), with DevTools / IDE / terminal panels revealing the rot beneath: hardcoded mock data, empty Supabase tables, "localhost:3000" deploys, `curl: connection refused`, TODO comments never resolved. Cinema-cyberpunk dashboard meets `console.log` audit.

## When NOT to use

- Genuine AI startup branding — would read as parody and damage credibility. Use `cyber-noir` for sincere AI/tech content instead.
- Wellness / lifestyle / soft content — completely wrong register.
- Pre-product visioning / pitch decks for ACTUAL builders — they need cyber-noir, not the vaporware mock.

## Variation hints

- **Dashboard ALWAYS top layer**: glowing cyber UI is the lie surface. DevTools / IDE / terminal panels are the unmasking layer. Never invert.
- **Use F12 / DevTools framing**: the most effective hook is "the dashboard is open, devtools panel is also open showing the HTML is `<div class="fake-metric">+320%</div>` — hardcoded".
- **Mock data labels do the rhetorical work**: every metric card gets a small red "MOCK" / "n = 0" / "NO BACKEND" annotation. "+320%" alone is the bait; "+320% [MOCK]" is the unmasking.
- **Supabase / localhost / curl references**: include "supabase: 1 row (demo)", "deployed to localhost:3000", "curl backend → connection refused" — these are the rhetorical heart, the cold technical proof.
- **Character role**: character is the SENIOR ENG / SECURITY AUDITOR / FRACTIONAL CTO who opened devtools and is showing the viewer what's actually missing. Cold-eyed knowing smirk. NEVER the founder showing off the dashboard.
