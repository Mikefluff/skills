# VAPORWAVE / RETRO-FUTURE

Use for content with irony, nostalgia, or consumer-culture commentary. The visual language is **80s/90s mall aesthetic + Greek statues + chrome 3D + sunset grids** — knowingly kitsch.

## When NOT to use

- Serious business — reads as parody.
- Hard tech — too soft.
- Academic — too playful.

## Variation hints

- More pink → bubblegum / pop-culture energy.
- More cyan + grid → cyber-techno energy.
- Heavier scanline / VHS → analog-decay melancholy.
- Add Japanese kana → late-Showa Tokyo energy.
