# STREETWEAR / HYPE

Use for product drops, limited editions, trend content, urgency-driven offers. The visual language is **sneaker-shop aesthetic + drop-date countdowns + screenprint texture + bleed-off headlines**.

## When NOT to use

- Anything that needs warmth / patience — too aggressive.
- Academic / scientific — wrong register.
- Wellness — too consumerist.

## Variation hints

- Bright safety orange BG → high-vis / construction-collab energy.
- Hi-vis lime BG → 90s rave / club-flyer energy.
- Photo-collage BG → editorial / lookbook energy.
- More holographic foil → premium-drop energy.
