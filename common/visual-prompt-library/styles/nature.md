# NATURE / ORGANIC

Use for content about nature, wellness, sustainability, organic products, gardening. The visual language is **botanical illustration + watercolor wash + kraft paper + handcrafted maker marks**.

## When NOT to use

- Urgent / hype content — too calm.
- Tech / engineering — wrong register.
- Tactical — too soft.

## Variation hints

- Soft green-blue gradient → ocean / forest / outdoor wellness.
- Sandy beige → desert / minimalist-natural energy.
- Terracotta → Mediterranean / earthy-craft energy.
- More watercolor splash → gallery / artisanal energy.
- More kraft texture → eco-product / sustainable-brand energy.
