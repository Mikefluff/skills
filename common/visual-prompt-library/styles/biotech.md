# BIOTECH / ORGANIC

Use for topics that involve internal processes, growth, transformation, or biological / health systems. The visual language is **scientific but warm** — glowing organic forms, cellular structures, soft gradients with bioluminescent accents.

## When NOT to use

- Hard business topics — too soft.
- Tactical / strategic content — too organic.
- Editorial / fashion — too clinical.

## Variation hints

- Darker background → late-night research / introspection energy.
- Lighter background → cellular biology / clean-lab energy.
- Brighter cyan accents → futuristic medical-tech.
- More mint / less cyan → wellness / mental health.
