# ART DECO / GATSBY

Use for content about luxury, wealth, elite status, timeless quality. The visual language is **1920s-30s art deco + gold accents + symmetric framing + sunburst medallions**.

## When NOT to use

- Mass-market consumer — too elite.
- Tech / startup — too ornamental.
- Casual / lifestyle — too formal.

## Variation hints

- Deep navy BG → high-society / private-club energy.
- Black + gold → speakeasy / Gatsby-night energy.
- Rich emerald → poker-room / casino energy.
- More marble pattern → museum / institutional-luxury energy.
- Add peacock feathers → flapper / 20s-party energy.
