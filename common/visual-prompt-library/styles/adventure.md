# ADVENTURE / OUTDOOR

Use for content about adventure, outdoor sports, expeditions, travel, achievement. The visual language is **dramatic landscape photography + summit-stamp medallions + topographic underlays + compass-rose framing**.

## When NOT to use

- Indoor / clinical — wrong register.
- Luxury / fashion — too rugged.
- Academic — too kinetic.

## Variation hints

- Mountain landscape → alpine / hiking / expedition energy.
- Ocean / surf → coastal / aquatic-sport energy.
- Sunset BG → arrival / golden-hour victory energy.
- Snowfield → polar / extreme-cold expedition energy.
- More compass + topo map → cartographic / scouting energy.
