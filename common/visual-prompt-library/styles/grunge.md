# GRUNGE / NEWSPAPER

Use for content that's confrontational, exposé-style, underground, or punk-energy. The visual language is **photocopied zine + newspaper masthead + ransom-note collage + marker scrawl**.

## When NOT to use

- Luxury / premium — wrong register.
- Wellness / lifestyle — too aggressive.
- Children's content — too raw.

## Variation hints

- More newsprint → real-newspaper exposé energy.
- More ransom-note → conspiracy / underground-zine energy.
- More marker scrawl → DIY / punk-flyer energy.
- More polaroids → evidence-board / detective energy.
- Heavier redaction → leak / classified-document energy.
