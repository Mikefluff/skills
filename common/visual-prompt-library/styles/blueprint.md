# BLUEPRINT / TECHNICAL

Use for content explaining how something works, process diagrams, architecture breakdowns, how-to. The visual language is **engineering blueprints + drafting paper + dimension lines + title-block panels**.

## When NOT to use

- Emotional / narrative content — too clinical.
- Beauty / lifestyle — too austere.
- Children's content — too technical.

## Variation hints

- Cyanotype blue BG → classic architectural blueprint.
- Graph paper white → engineering-notebook energy.
- Craft paper / tan → fabricator-shop / maker energy.
- More exploded-view → product-launch / spec-sheet energy.
- Heavier dimension annotations → reverse-engineering energy.
