# NORDIC MINIMAL / QUIET-PREMIUM

## Reference orientation

Think Helsinki magazine restraint, Marimekko-era graphic discipline, mid-century Scandinavian editorial design. The dominant emotional note is *calm-considered-expensive* — never busy, never decorative for its own sake.

## When NOT to use

- Urgent / hype / FOMO content — the restraint reads as indifference; use streetwear or grunge instead.
- Emotionally loud topics (scandals, criticism, raw exposés) — the quiet-premium register undercuts the message; use brutalist or grunge.
- Dense data-heavy slides — the asymmetric-with-negative-space signature breaks; use scientific or blueprint.

## Variation hints

- Single-accent discipline: use vermillion ONCE per composition, never twice. The pop only works when it's solitary.
- Hairlines are ALWAYS thin (≤1pt feel). Thicker rules read as brutalist, not Nordic.
- The geometric primitive (circle / square / triangle) anchors negative space — it's structural, not decorative. Pick exactly one per slide.
- Keep typography weight contrast modest — heavy display + light body works; black + thin is too dramatic for the register.
