# BRUTALIST / CONCRETE

Use for content that's uncompromising — civic critique, hard business truths, power analysis, anti-decorative manifestos. The visual language is **raw concrete + industrial signage + heavy type bleed**.

## When NOT to use

- Anything that needs warmth — too cold.
- Luxury / lifestyle — too austere.
- Beauty / fashion — too industrial.

## Variation hints

- More yellow accent → hazard / warning energy.
- More rust red → decay / civic-failure energy.
- Pure gray + black → architectural manifesto energy.
- Add cardboard texture → DIY / zine energy.
