# No synthetic AI-words

Карта типичных «умных» слов, которые AI-модели любят оставлять даже в художественной прозе, и человеческих замен под каждый случай.

## NO SYNTHETIC AI-WORDS (даже если стояло в оригинале)

«Рамка», «нарратив», «дискурс», «парадигма», «концепт», «оптика» (как метафора) — нейрослоп. Чистить даже если автор так написал в первом черновике.

Замены:
- «рамка» → «модель / язык / логика / описание»
- «нарратив» → «история / версия / рассказ»
- «дискурс» → «разговор / спор / поле»
- «парадигма» → «подход / способ смотреть / модель»
- «концепт» → «идея / понятие / замысел»
- «оптика» (метафора) → «угол зрения / способ смотреть / точка наблюдения»

(Часть этого уже в writer Layer 1 категория 22; здесь — для художки, чтобы не пропустить как «оригинал».)
