# Banned words

Strip these on sight from microcopy. Each one marks the text as low-quality.

---

## Jargon (system-speak)

| ❌ Banned | ✅ Replacement |
|---|---|
| `Authenticate` | `Sign in` |
| `Authentication` | `Sign-in` |
| `Authorization` | `Permission` / `Access` |
| `Initialize` / `Initialization` | `Set up` / `Setup` |
| `Validate` / `Validation` | `Check` (sometimes: skip entirely) |
| `Execute` | `Run` |
| `Terminate` | `End` / `Stop` / `Cancel` |
| `Instantiate` | `Create` |
| `Configure` | `Set up` |
| `Configuration` | `Settings` |
| `Deprecated` | `Old version` / `No longer supported` |
| `Endpoint` | `URL` (user-facing) |
| `Iterate` | `Loop through` (or skip; users don't need this concept) |
| `Provision` | `Set up` / `Create` |
| `Migrate` | `Move` (or `Update` if it's an upgrade) |

---

## Hedge words (weak)

| ❌ Banned | ✅ Replacement |
|---|---|
| `Just` (as filler: "just click here") | Delete |
| `Simply` | Delete (if it's not simple, the word doesn't help; if it is, you don't need to say it) |
| `Easy` | Delete (let the action prove it) |
| `Quickly` | Delete (or replace with time estimate: "takes 2 minutes") |
| `Please` (in buttons) | Delete |
| `Kindly` | Delete |
| `Would you like to` | `Want to` (or skip the question) |
| `Maybe` | Delete (commit) |
| `Probably` | Delete or rephrase |
| `Possibly` | Delete or rephrase |
| `Approximately` | `About` (or commit to a specific number) |

## Robot-speak / corporate

| ❌ Banned | ✅ Replacement |
|---|---|
| `Reach out` | `Contact` / `Email` / `Message` |
| `Touch base` | (delete entire phrase) |
| `Circle back` | `Follow up` |
| `Leverage` | `Use` |
| `Synergy` / `Synergistic` | Delete |
| `Holistic` | Delete |
| `Stakeholder` | (often deletable in user-facing copy; users don't think of themselves as "stakeholders") |
| `Going forward` | `From now on` (or delete) |
| `At the end of the day` | Delete |
| `Pivot` | `Change direction` / `Shift` |
| `Bandwidth` (meaning capacity) | `Time` / `Capacity` |
| `Take advantage of` | `Use` |
| `Going forward` | `Now` / `From now on` |

## Apologies overused

| ❌ Excessive | ✅ Reserved use |
|---|---|
| `Sorry, but...` for routine failures | Delete; just state what happened |
| `Apologies for...` for routine | Delete |
| `Unfortunately...` | Delete; just state the consequence |
| `Oops!` | Delete (infantilizing) |
| `Oh no!` | Delete |
| `Uh oh` | Delete |
| `Looks like...` (as a filler) | Just state the fact |

Reserved for: data loss, prolonged outage, payment failures, genuine inconvenience.

---

## Filler / verbal tics

| ❌ Banned | ✅ Replacement |
|---|---|
| `Click here` | Use the verb of the action: `Download`, `Sign up`, `Learn more` |
| `Click to...` | Same — replace with the verb |
| `Tap to...` (mobile equivalent) | Same |
| `In order to` | `To` |
| `Due to the fact that` | `Because` |
| `At this point in time` | `Now` |
| `For the purpose of` | `To` / `For` |
| `In the event that` | `If` |
| `With regard to` | `About` |
| `With respect to` | `About` / `For` |
| `In light of` | `Given` / `Because of` |
| `As a result of` | `Because` |

## Overused buzzwords

These mark text as marketing fluff:

- `Revolutionary`
- `Cutting-edge`
- `Game-changing`
- `Disruptive`
- `Next-generation`
- `World-class`
- `Best-in-class`
- `Industry-leading`
- `Award-winning` (unless literally cited with the award)
- `Innovative`
- `Powerful`
- `Robust`
- `Enterprise-grade`
- `Solution` (as in "our solution") — usually replaceable with the actual product noun

In microcopy specifically, these almost always make text worse. They're empty calories.

## Forbidden in error messages specifically

| ❌ | Why banned |
|---|---|
| `Unknown error` | Tells user nothing |
| `An error occurred` | Generic; describe WHAT failed |
| `Something went wrong` | Use ONLY if you genuinely don't know what failed AND can't offer next step |
| `Error code: 42` (alone) | Codes belong in logs, not user-facing without explanation |
| `Operation failed` | What operation? |
| `Action could not be completed` | What action? |
| `Please try again` (alone) | If user can try again, say so AND say what's likely to fix it |
| `Contact support` (alone) | Tell them what's wrong first |

## Quick test

For any microcopy you write, run this strip-search:

1. Find "just" — can it go?
2. Find "simply" / "easy" / "quickly" — can it go?
3. Find "please" — if button, delete; if elsewhere, evaluate
4. Find "click here" / "click to" — replace with the verb
5. Find "in order to" → "to"
6. Find "due to the fact that" → "because"
7. Find any of the jargon list — replace with plain word
8. Find any of the corporate-speak list — usually delete or replace
9. Find apologies for routine actions — delete

After one pass through this checklist, the text is typically 20-30% shorter and noticeably crisper.

---

## What to add (positive direction)

If stripping leaves something too bare, add:

- **Specific numbers / dates / times** where applicable
- **The next action** the user can take
- **A piece of useful context** if it's load-bearing

But don't add filler. Better to be shorter and clearer than longer and "polished".
