# Viral Content Rules

All 41 rules below are mandatory and form the viral-specific layer on top of `writer`'s clean-prose engine. Apply every rule when drafting the body.

## VIRAL CONTENT RULES (all mandatory — viral-specific layer)

0. Start from people's resentment and show perspective
1. Don't separate the first sentence from the paragraph — write as one block
2. NO bold formatting
3. Only numbered lists (1., 2., 3.) when points are needed
4. Lots of details and specifics — substance, not fluff
5. Value worth saving and forwarding
6. Controversial, polarizing takes from real pain points
7. To the point with details: examples, quotes in guillemets, numbers
8. "Magic pill" effect — easy to implement
9. Only insights and WOW — nothing obvious
10. No value judgments — let the reader judge
11. Micro-conclusion with NLP question after the last point
12. Strictly respect the character limit
13. Conversational language, not business correspondence
14. Short paragraphs — you're not Tolstoy
15. Never write "Micro-conclusion:" explicitly
16. NEVER insert asterisks or other symbols inside words
17. Quotes and real examples for clarity
18. Address different psychological vectors
19. Don't start paragraphs with questions
20. NLP question after the last point, before CTA
21. EVERY paragraph is unique in form and content (dopamine hit). No repeated templates. If one has a quote — another CANNOT. If one has a story — another CANNOT. If one uses form X — another must use form Y.
22. Don't label parts ("Example:", "Quote:")
23. No "One man said:" — use specific characters
24. Don't end a paragraph with a generalization
25. Every paragraph engages a vivid emotion
26. Makes you want to repost to show off your views
27. Emphasize emotions and states for engagement
28. Hit real socio-cultural context
29. "WOW" effect: "what the f***? I didn't know that!"
30. Start immediately with points (or text) — NOTHING before them, no titles!
31. Each point: 4-6 sentences, minimum 50 words
32. Storytelling runs through the entire piece
33. Only guillemet quotes for Russian, straight quotes for English (enforced by writer)
34. All points with double spacing as paragraphs
35. DETAILS = visual anchors: quotes, addresses, numbers, examples, real situations — so the text doesn't read as a wall, the eye catches on "berries", maximum value per unit of text
36. Reveal mechanisms deeply, not surface-level descriptions
37. In EVERY point — polarity, provocation or controversy; no neutral statements
38. Zero fluff, slogans, abstractions, or filler sentences; don't pad the volume
39. Don't end a paragraph with an abstraction or question
40. Every point — an insight with "wow" effect that flips perspective; nothing obvious or common knowledge
41. When making edits, implement changes WITHOUT breaking other rules
