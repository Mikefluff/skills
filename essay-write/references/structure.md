# STRUCTURE — non-fiction chapter / longread

Типичная глава нон-фикшн (3-5 страниц):

1. **Лид** (1-2 абзаца) — конкретная сцена, факт, цитата или провокация, цепляющая в тезис главы. НЕ виральный hook, но и не «В этой главе мы рассмотрим».
2. **Тезис** (1 абзац) — что именно глава доказывает или объясняет.
3. **Раскрытие** (3-7 секций) — каждая раскрывает один аспект тезиса:
   - механизм (как это работает)
   - источник (кто это показал)
   - пример (где это видно)
   - возражение и ответ (если уместно)
4. **Переход к следующей главе** или закрытие — без виральной NLP-вопросительной концовки. Может быть открытый вопрос, парадокс, авторский поворот.

Внутри секции — длинные абзацы, не дроблённые на «1.», «2.». Списки — только если автор явно их использует в исходнике.

## Hypothesis chapters — V/H/P markers

В главах, где встречаются утверждения трёх разных уровней достоверности (характерно для popular-science / philosophy-of-science), полезны **inline-маркеры**, отделяющие установленный факт от авторской гипотезы:

- **`[V]` / `[VERIFIED]`** — верифицированное утверждение (есть источник, проверяемо).
- **`[H]` / `[HYPOTHESIS]`** — гипотеза автора (не доказана, явно помечена).
- **`[P]` / `[PERSONAL]`** — провокация / личное мнение (намеренная для эффекта, не претендует на истину).

В переводах маркеры **сохраняются английскими** во всех языках без локализации — это часть машиночитаемого слоя текста.

### Обязательный блок «Что опровергнет эту гипотезу»

Если глава вся целиком — гипотеза (а не цепочка установленных тезисов), она обязана содержать блок **«Что опровергнет эту гипотезу»**. Без него глава перестаёт быть научным нон-фикшном и становится проповедью.

Формат блока:
- Перечислить 2-4 конкретных условия / экспериментальных результата / наблюдения, которые опровергли бы центральный тезис главы.
- Формулировать в утвердительной форме («Если измерения покажут X, гипотеза не работает»), не риторически.

### Опциональность в обычных главах

В обычных главах (не сплошных гипотезах) маркеры опциональны — но если в главе есть гипотезы, **лучше всё равно помечать**. Систематическая разметка повышает доверие читателя и делает уровень достоверности видимым на скане.
