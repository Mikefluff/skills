# SOURCING (обязательно для научпоп тезисов)

Для НК и любого нон-фикшн с научными утверждениями — каждый тезис подкреплён источником.

## Процесс:
1. Сформулировать тезис
2. Найти источник через `WebSearch` (приоритет: рецензируемые журналы → препринты arXiv/bioRxiv → научно-популярные книги с указанием первичной литературы → серьёзная пресса)
3. Если тезис не подтверждается источниками — переформулировать как авторскую гипотезу, явно помеченную
4. Цитирование в формате книги: «Имя с соавторами (Journal, YEAR)» в нарративе или «В YEAR группа Имя показала…» развёрнуто

## Запрет:
- Никаких выдуманных цитат, фамилий, лабораторий, экспериментов
- Никаких «учёные считают» / «исследования показывают» без конкретного источника (writer Layer 1 категория 14 ловит)
- Никаких «X et al. (Journal, YEAR)» — это академический формат, режет глаз в художественно-публицистическом нон-фикшн. Развёртывать.

## Source list в конце главы (опционально):
Если глава готовится к печатной публикации (Эксмо), в конце — список источников в формате LaTeX `\bibitem` или сноски `\footnote{}`. В рабочей версии — можно метки `[ref: Imya 2024]` для последующей сборки библиографии.
