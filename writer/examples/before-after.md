# Before / After — calibration examples

Канонические рерайты. Использовать для калибровки: если по этим парам непонятно, какой принцип сработал — перечитать `references/structural-prose.md` или соответствующую категорию из `references/neuroslop-categories.md`.

Формат:

```
BEFORE: ...
AFTER:  ...
WHY:    {категория / паттерн}
```

---

## STACCATO

```
BEFORE: Нога вырастает правильная. С правильным числом пальцев. В правильном месте. С правильной ориентацией.
AFTER:  А потом заново проходят специализацию по тому же чертежу, что и в эмбрионе, и нога вырастает прежняя — с теми же пальцами, на том же месте, с той же ориентацией, что у отрезанной.
WHY:    Четыре односоставных подряд. Добавлен подчинительный союз «что» + причинно-следственная связка «потом... и...».
```

```
BEFORE: Я видел, как реальность пересобирается. Буквально. В девяносто восьмом. На диалапе. В Ставрополе.
AFTER:  В девяносто восьмом, сидя на диалапе в Ставрополе, я буквально видел, как реальность пересобирается.
WHY:    Биографические фрагменты собраны в одно предложение через деепричастный оборот «сидя на».
```

```
BEFORE: BOOM — это НИИЧАВО. AfrikaBurn — это НИИЧАВО. Лампа — это НИИЧАВО.
AFTER:  BOOM, AfrikaBurn, Лампа — каждый из них работает как очередное НИИЧАВО, временное, на неделю собирающееся в пустыне или на берегу.
WHY:    Анафорическая цепочка «X — это Y» свёрнута в перечисление + общая характеристика через причастный оборот.
```

## DOUBLE_NEG

```
BEFORE: не считал. Ни трещин, ни процентов, ни шариков.
AFTER:  перестал считать — трещины на потолке, проценты когерентности, шарики воспоминаний; счёт отпустил меня первым
WHY:    Тройное отрицание заменено утверждением + конкретизацией.
```

```
BEFORE: Я не экстрасенс. Не пророк. Не тот мужик из рекламы.
AFTER:  Я и не экстрасенс, и не пророк, и не тот мужик из рекламы
WHY:    «Не X. Не Y. Не Z.» заменено на однородные «и не X, и не Y, и не Z» — без точек, с союзом.
```

```
BEFORE: — Без вмешательства, без подготовки, без причины.
AFTER:  — Стек открывается сам собой — спонтанно, безо всякого вмешательства, подготовки или видимой причины.
WHY:    Реплика персонажа: добавлен субъект + объединение трёх «без» в один предложный оборот «безо всякого X, Y или Z».
```

## CHUNK / «Просто --- X»

```
BEFORE: Просто --- эволюция.
AFTER:  Просто эволюция в чистом виде — давление среды, отбор и статистика.
WHY:    «Просто» превращено в наречие, добавлены конкретные механизмы.
```

```
BEFORE: Артём натянул сеть. Без объяснений. Просто — взял и натянул.
AFTER:  Артём надавил, безо всяких объяснений просто взяв провисающую сеть и натянув её.
WHY:    Три обрубка собраны в одно предложение с деепричастным оборотом «безо всяких объяснений просто взяв... и натянув её».
```

## INVERSION

```
BEFORE: Звать его мы стали сынулей.
AFTER:  Мы быстро стали звать его сынулей.
WHY:    Verb-first инверсия (калька с английского). Восстановлен SVO.
```

```
BEFORE: имена двоюродных её родственников
AFTER:  имена её двоюродных родственников
WHY:    Притяжательное местоимение должно стоять перед прилагательным.
```

---

## REPEAT

```
BEFORE: цикл размыкается, программа выходит из бесконечного цикла
AFTER:  цикл размыкается, программа выходит из бесконечного повтора
WHY:    Корень «цикл» дважды в одном предложении. Второе вхождение заменено синонимом.
```

```
BEFORE: положил на музыку и попросил начитать поверх этой музыки
AFTER:  положил на музыку и попросил начитать поверх дорожки
WHY:    «Музыка» дважды → второе вхождение через «дорожку».
```

## NEURAL_METAPHOR

```
BEFORE: теория трещит по швам
AFTER:  теория не выдерживает
WHY:    «Трещит» как метафора неисправности — слово-метафора из AI-словаря. Заменено на прямой глагол.
```

```
BEFORE: больной нерв всего разговора
AFTER:  больная мозоль всего разговора
WHY:    «Нерв» как метафора. Заменено на идиоматичный русский эквивалент.
```

```
BEFORE: связка нас держит на дистанции
AFTER:  связка не отпускает нас на дистанцию
WHY:    «Держать» как абстрактная метафора. Заменено на конкретный глагол.
```

## BUREAU_INV + AI_INTENSIFIER

```
BEFORE: Данный подход является беспрецедентным революционным изменением, осуществляющимся в рамках стратегической инициативы.
AFTER:  Это новый подход. Его запустили в рамках стратегии.
WHY:    Снято всё разом: «данный»→«это», «является»→прямое утверждение, «беспрецедентный»+«революционный»→«новый», «осуществляющимся»→«запустили».
```

## FILLER_INTRO + AI_BRIDGE + GPT_FILLER

```
BEFORE: В современном мире, как известно, важно понимать, что таким образом мы погружаемся в детали.
AFTER:  Здесь важно понимать детали.
WHY:    Снято: «В современном мире» (FILLER_INTRO), «как известно» (FILLER_INTRO), «таким образом» (AI_BRIDGE), «погружаемся в детали» (GPT_FILLER). От смысловой нагрузки осталось «важно понимать детали».
```
