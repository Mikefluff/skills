# Виральный пост в Telegram за один заход

Сценарий: тема в голове («утренние ритуалы продуктивных людей»), хочется получить готовый текст для копипасты в Telegram. Никакой ручной правки заголовков, подсчёта пунктов и вылавливания нейрослопа — всё это берёт на себя `viral-text`.

## Шаг 1. Запустить скилл

В Claude Code:

```
/viral-text утренние ритуалы продуктивных людей
```

По умолчанию: Telegram, 5 пунктов, русский, ключ для CTA скилл подберёт сам.

## Шаг 2. Research-фаза

Скилл не пишет с нуля. Сначала он идёт в WebSearch + WebFetch и собирает 3 ведра: FACTS / INSIGHTS / QUOTES. После research-фазы он показывает короткую сводку перед тем, как сесть писать:

```
Research found:
- 26% американцев следуют утренней рутине ≥ 4 раз в неделю (Sleep Foundation, 2024)
- Tim Cook встаёт в 4:00 и читает почту 1 час до тренировки (источник: Time, интервью 2017)
- метаанализ 14 исследований: «morning person» — на 60% реже жалуются на выгорание (Chronobiology Intl., 2022)
```

На этом этапе можно перебить и сказать «возьми ещё пример с Mark Wahlberg» или «пропусти статистику, нужны только цитаты». Если research вернул пустоту — см. troubleshooting ниже.

## Шаг 3. Шесть слоёв вывода

Скилл собирает текст по фиксированной структуре:

1. **Хук** — 7-12 слов, одна CAPS-капс, наживка-скобка, заканчивается двоеточием.
2. **5 пронумерованных пунктов** — каждый со своим типом (цитата / пример / история / факт / данные), 4-6 предложений, разная полярность.
3. **Микро-вывод с NLP-вопросом** — отдельный абзац, не внутри последнего пункта.
4. **CTA** с ключевым словом в `==скобках==`.
5. **Writer-пасс** — 4 слоя чистки (нейрослоп regex 23 категории + структурная синтетика + хирургические правки + чтение вслух).
6. **Viral Layer A/B** — финальная проверка хука и тела на 41 виральное правило, и «репостнул бы я это» вопрос.

Шаги 5-6 идут молча. Пользователь видит только итоговый текст.

## Шаг 4. Готовый текст

Иллюстративный (не дословный, формат для калибровки):

```
ОДНО утро в неделю (как у топ-100 CEO) делает остальные шесть терпимыми:

1. Tim Cook встаёт в 4:00 не ради продуктивности, а чтобы час побыть до того, как начнётся
очередь чужих запросов. Он отвечает на 800 писем в день. Если первый час дня отдан
почтовому ящику — день уже не твой. У него — твой. Это не дисциплина, это пограничный режим.

2. Метаанализ 14 исследований (Chronobiology International, 2022) показал: люди с устойчивой
утренней рутиной на 60% реже сообщают о выгорании. Не потому что они «лучше». Потому что
рутина — это якорь, на который вешается остальной хаос. Хаоса меньше не становится. Просто
есть точка, к которой ты возвращаешься в 6 утра.

3. Mark Wahlberg публикует свой график в Instagram и над ним пять лет смеются. 2:30 подъём,
криосауна в 3:45, молитва в 4:15. Когда смеётся весь интернет — это работает на узнаваемость
лучше любого PR. Смешные ритуалы запоминают, эффективные забывают.

4. Половина «утренних рутин» в LinkedIn — это фотографии медитации, которые делает супруг
снимающего. Реальная утренняя дисциплина не фотогенична: шесть минут планки, две страницы
скучного дневника, очень холодный душ. Никто не выкладывает скучное.

5. Опрос Sleep Foundation (2024): 26% американцев следуют утренней рутине четыре и более
раз в неделю. Из них только 8% — раньше 6 утра. То есть «вставать рано» — это маркетинговый
ярлык, а не статистическая норма. Норма — в 7:15 включить чайник по тому же сценарию,
что и вчера.

Утренний ритуал — это не способ стать лучше. Это способ договориться с собой о том, как
именно начнётся следующее столкновение с миром. А у тебя есть такая договорённость?

Если откликнулось — пиши ==РИТУАЛ==, разберём, какой именно режим работает в твоей неделе.
```

*(Текст выше — иллюстративный, для демонстрации формата. Реальный вывод зависит от research.)*

## Переопределение дефолтов

```
/viral-text utr ритуалы platform=instagram points=3 lang=en
```

Доступные параметры (см. [viral-text/references/platforms.md](../../viral-text/references/platforms.md) для полного списка):

- `platform=` — `telegram` (4096) / `instagram` (2200) / `threads` (500) / `twitter` (280) / `linkedin` (3000) / `facebook` (any). По умолчанию Telegram.
- `points=` — 3 / 5 / 7. По умолчанию 5.
- `lang=` — `ru` / `en` / `es` / `pt`. По умолчанию русский (или язык темы).
- CTA word — любое ключевое слово; если не указать, скилл подбирает сам.

## Когда НЕ использовать viral-text

- **Длинный лонгрид с источниками и аргументацией** — это `essay-write`. Виральный формат с numbered points и NLP-вопросом убивает аргумент.
- **Фрагмент художественной прозы** — `prose-edit`. Hook + CAPS-слово в художке выглядят как реклама.
- **Просто почистить текст** — `writer clean`. Если уже написан хороший абзац, не нужно его «виралить».

## Troubleshooting

### Research вернул пустоту или только мусор

Попробуй сузить тему. «Утренние ритуалы» — слишком общая; «утренние ритуалы CEO технокомпаний 2022-2024» даёт WebSearch конкретные публикации. Или подайте 2-3 источника вручную: `/viral-text утренние ритуалы (источники: https://… https://…)` — скилл их подтянет через WebFetch.

### Хочу переписать только один пункт

Скажи прямо: «перепиши пункт 3, без статистики, замени на сценку из жизни». Скилл переделает один пункт без перегенерации остальных. Writer-пасс прогонится снова поверх правки.

### Хук получился слабый

Дай критерий: «хук без CAPS, не вопросительный, заканчивается двоеточием с цифрой». Скилл уважает пользовательские ограничения поверх дефолтов.

### Длина перевалила за лимит платформы

Скилл сам подрезает самый длинный пункт, сохраняя CTA и микро-вывод. Если итог всё равно > лимита — попроси уменьшить `points=3` или укоротить формулировки.
